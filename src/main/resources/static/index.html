日本語 NIHONGO App

Học tiếng Nhật một cách thú vị! 🎌

Server đang chạy trên port 8080

📋 API Endpoints chính:

POST /api/v1/auth/login — Đăng nhập

POST /api/v1/auth/refresh — Làm mới token

POST /api/v1/gacha/spin — Gacha

POST /api/v1/shop/purchase — Mua vật phẩm

POST /api/v1/lessons/{id}/complete — Hoàn thành bài học

GET /api/v1/wallet/balance — Kiểm tra số dư

GET /actuator/health — Kiểm tra health
